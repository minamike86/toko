# Governance Baseline

Gunakan dokumen ini saat request menyangkut fitur baru, perubahan scope, roadmap, non-goals, ADR, atau lifecycle dokumentasi.

## Source Documents

- product-vision.md
- MVP Roadmap dan Arsitektur Awal.md
- Non-Goals.md
- documentation_lifecycle_policy.md
- circle_update_fitur_dokumentasi.md

## Core Rules

- Product Vision menentukan arah produk.
- MVP Roadmap menentukan tahap dan scope.
- Non-Goals menentukan batas eksplisit.
- Documentation Lifecycle menentukan apakah dokumen baru layak dibuat.
- Circle Update Fitur wajib dipakai untuk fitur baru atau perubahan behavior signifikan.

## Default Decision

- Jika fitur sesuai roadmap dan tidak melanggar non-goals → LANJUT atau PATCH REQUIRED.
- Jika fitur melanggar non-goals → STOP atau OUT OF SCOPE.
- Jika dokumen belum sinkron → PATCH REQUIRED.
